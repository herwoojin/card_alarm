# 실적ON

> 카드 결제 문자를 읽어 실적을 추적하고, 구간을 넘긴 순간 다음 카드로 갈아타게 해주는 모바일 웹앱

카드를 3장 이상 쓰면 매달 같은 손해가 반복된다. 한 장은 최고 구간을 넘겨 초과분이 버려지고, 다른 한 장은 몇 만원이 모자라 한 달치 혜택을 통째로 놓친다. 그리고 그 사실을 **월말 명세서를 받고 나서야** 안다.

실적ON은 카드사가 결제 직후 보내는 승인 문자를 읽어, 명세서를 기다리지 않고 지금 어느 카드를 써야 하는지 알려준다.

## 프로토타입 실행

```bash
# 정적 서버로 열면 PWA 기능까지 동작한다
npx serve .
# 또는
python3 -m http.server 8080
```

브라우저에서 열고 **[샘플 데이터로 둘러보기]**를 누르면 카드 3장·거래 30건이 들어간 상태를 볼 수 있다. 샘플에는 실적 초과 사례가 포함돼 있어 핵심 기능인 "초과 → 대체 카드 추천"이 첫 화면에 나타난다.

`file://`로 열어도 대부분 동작하지만, 서비스워커와 공유 시트는 HTTPS 또는 localhost가 필요하다.

## 프로토타입에 이미 들어간 것

- **문자 파서** — 카드사 13종 인식, 누적금액 오인식 방지, 가맹점 3단 폴백 추출, 업종 15종 자동 분류, 취소 거래 음수 처리
- **실적 엔진** — 주기 계산, 구간 판정, 실적 제외 3단 우선순위, 진행률·초과액 산출
- **최적화 엔진** — 초과/달성가능/달성어려움 3유형 조치 생성, 대체 카드 선정, 예상 이득 계산
- **분석** — 월별 추이, 업종별 분해, 연간 전망
- **카드 게이지** — 카드 모양 안에서 실적이 차오르고 구간이 눈금으로 새겨지는 시그니처 UI
- **수집 경로** — Web Share Target, 클립보드 감지, 일괄 붙여넣기, 미인식 문자 직접 입력

파서는 11종 실제 문자 형식으로 검증했고, 안내 문자(청구·이벤트) 반려까지 동작한다.

## 프로덕션에서 바꿔야 할 것

| 프로토타입 | 프로덕션 |
|---|---|
| 단일 HTML + 바닐라 JS | Next.js 14 App Router + TypeScript |
| `localStorage` | Dexie (IndexedDB) — 용량과 인덱스 때문에 필수 |
| 인라인 스타일 | Tailwind + shadcn/ui |
| 테스트 없음 | 골든 케이스 40건 + 도메인 커버리지 90% |

전환 절차는 `PROMPT.md`의 20단계를 순서대로 따르면 된다.

## 설계 원칙

**1. 결제 데이터는 기기를 벗어나지 않는다.**
회원가입 없음, 서버 전송 없음, 애널리틱스 없음. CSP의 `connect-src 'self'`로 강제한다. 카드번호 전체·CVC·비밀번호는 스키마에 자리조차 두지 않는다.

**2. 오래 붙잡지 않는다.**
세션 체류 시간을 **낮추는 것**이 목표다. 결제 직전 3초 안에 답을 주고 사라진다.

**3. "더 쓰세요"만 말하지 않는다.**
구간 도달이 비현실적이면 "이번 주기는 접고 다른 카드에 집중하세요"라고 권한다. 3만원 혜택을 받으려고 20만원을 더 쓰게 만드는 앱은 사용자 편이 아니다.

**4. 숫자를 단정하지 않는다.**
카드 혜택 조건은 사용자가 입력한 값으로만 계산한다. 템플릿의 숫자는 형태를 보여주는 예시일 뿐이며, 그 사실을 항상 화면에 함께 표시한다.

**5. 실패한 문자를 버리지 않는다.**
인식하지 못한 문자는 사유와 함께 남고, 사용자가 직접 채우면 살아난다. 정확도 지표를 화면에 정직하게 노출한다.

## 알려진 제약

- **웹앱은 문자를 직접 읽을 수 없다.** 공유 시트(2탭), 클립보드, iOS 단축어·Android 자동화 연동으로 우회한다. 완전 자동화는 네이티브 래퍼가 필요하며 Play 정책 심사 대상이다.
- **카드 조건을 사용자가 입력해야 한다.** 카드사 API 연동이 없으므로 불가피하다. 템플릿으로 부담을 줄인다.
- **실적 주기가 전역 설정 하나다.** 카드사별 기준일 차이는 v1.1에서 분리한다.
- **할부는 승인월 전액 반영이다.** 청구월 분할 정책은 v1.1.
- **로컬 저장소가 유일한 저장소다.** 브라우저 데이터를 지우면 복구할 수 없다. 백업 내보내기가 사실상 필수다.
